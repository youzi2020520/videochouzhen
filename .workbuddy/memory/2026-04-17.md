## 新功能：AI 识别分镜表 + Excel 导出

**UI 改动**：
- 移除 pdf-template 选择器（不再有标准/导演/艺术海报三个模板）
- 新增"AI 识别分镜"按钮（Pro 功能）
- 新增"导出 Excel"按钮（Pro 功能）
- 顶部新增 AI 次数徽章（`ai-quota-badge`）
- 帮助弹窗内新增 Claude API Key 输入框

**用量限制逻辑**（`checkAIQuota`）：
- Free 用户：终身 1 次，用 `localStorage cine_free_ai_used`
- Pro 用户：每天 15 次，用 `localStorage cine_pro_ai_date / cine_pro_ai_used`

**AI 识别流程**（`startAIStoryboardAnalysis`）：
1. 检测用量，不够则弹 Toast
2. 检查 Claude API Key（`cine_claude_key`），无 Key 弹提示
3. 逐帧调用 Claude Haiku vision API（`claude-3-5-haiku-20241022`）
4. 结果存入 `storyboardAIResults[]`
5. 底部进度条实时显示识别进度

**Excel 导出**（`exportStoryboardExcel`）：
- 读取模板结构：编号/时间/景别/风格/画面/画面描述
- 用 SheetJS CDN (`xlsx.full.min.js`) 生成标准 xlsx
- 列宽：A=8, B=12, C=18, D=20, E=32, F=50
- 行高：表头30px，数据行90px

**新增状态变量**：`storyboardAIResults[]`、`isAIAnalyzing`
**新增弹窗**：`pdf-preview-modal` 复用为 AI 识别确认弹窗
**新增元素**：`ai-progress-bar`（底部固定进度条）、`ai-quota-badge`
