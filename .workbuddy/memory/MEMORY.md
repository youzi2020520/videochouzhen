# MEMORY.md - 视频抽帧助手项目记忆

## 项目概述
- **产品名**：CineMagic 视频抽帧助手
- **定位**：浏览器端 AI 视频抽帧 + 调色 + 分镜表导出工具，面向视频创作者
- **技术栈**：纯前端（HTML/CSS/JS），Vercel 部署，server.js 为 Express 适配层
- **授权系统**：后端验证授权码，存 localStorage（cine_pro / cine_expiry）

## PRO 模式功能划分（2026-04-17 更新）
- **Free 用户**：AI 识别分镜（20张终身额度）+ 无限导出 Excel
- **Pro 用户**：AI 识别分镜（每天100张额度）+ 无限导出 Excel + **AI 智能调色**（完整模块，仅 Pro 可见）

## 产品结构
- `index.html`：主工具页面（核心功能）
- `admin.html`：授权管理后台
- `server.js`：Express 服务端（含授权 API）
- `style.css`：全站样式
- `vercel.json`：Vercel 部署配置

## 核心功能
- **Free**：基础抽帧（手动/音频峰值）、基础调色、全尺寸 ZIP 导出
- **Pro**：AI 场景检测抽帧、高级调色（电影感/赛博朋克/日系等 9 种）、分镜表 PDF（3 种模板）、批量操作

## 用户偏好（已知）
- 简洁沟通，信任助手做设计决策

## 项目经验

### 启动本地服务器
server.js 是 Vercel 适配（无 `app.listen`），本地启动需要：
```bash
node -e "const app = require('./server.js'); app.listen(3000, () => console.log('Server running on port 3000'));"
```
